# Amazon Beauty Products Analysis

A Python-based data analysis and recommendation project exploring Amazon Beauty product reviews, user–item interactions, rating patterns, predictive modeling, and optimization.

## Project Overview

This project investigates user interactions with beauty products on Amazon using review and rating data. It combines exploratory data analysis, feature engineering, machine learning, dimensionality reduction, clustering, and mathematical optimization to examine product preferences and support data-driven recommendation analysis.

The project is implemented in Python using a Jupyter Notebook.

## Research Objectives

- Explore the structure and characteristics of Amazon Beauty product review data.
- Analyze rating distributions, product popularity, and user interaction patterns.
- Examine temporal trends and product-category differences.
- Develop predictive models using user-, item-, category-, and time-related features.
- Evaluate model performance using regression and classification metrics.
- Explore clustering, dimensionality reduction, and optimization techniques within the recommendation workflow.

## Dataset Description

The dataset contains Amazon Beauty product review interactions. The implementation uses the following fields:

| Variable | Description |
|---|---|
| UserId | User identifier |
| ProductId | Product identifier |
| ProductType | Product category/type |
| Rating | User-provided product rating |
| Timestamp | Unix timestamp of the interaction |

## Methodology

### 1. Data Processing and Profiling

The notebook loads selected variables, converts Unix timestamps into datetime values, and derives year, month, quarter, and year-month features. It also constructs a binary positive-rating indicator.

Dataset profiling examines user activity, product interactions, product-type coverage, rating statistics, missing values, and interaction-matrix sparsity.

### 2. Exploratory Data Analysis

Exploratory analysis investigates rating distributions, user and product interaction frequencies, product-category patterns, temporal activity, and the long-tail distribution of product popularity.

### 3. Model Dataset Construction

The modeling workflow uses chronological train, validation, and test partitions. It applies minimum interaction thresholds to users and products and supports proportional sampling with a maximum modeling dataset size of 50,000 records.

### 4. Feature Engineering

The feature construction process incorporates user-level, product-level, and category-level statistics, including interaction counts, average ratings, rating variability, category diversity, and time-related variables.

### 5. Predictive Modeling and Evaluation

The implementation imports and uses machine-learning tools for predictive analysis, including tree-based models, gradient boosting, neural-network approaches, and classification methods.

Evaluation utilities include:

- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- Precision
- Recall
- ROC-AUC

### 6. Additional Analytical Techniques

The project also includes dimensionality reduction, clustering, and mathematical optimization components. These are implemented using PCA, Truncated SVD, K-Means, and mixed-integer linear programming functionality.
